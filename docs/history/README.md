# Historique des sessions produit/tech

Ce dossier conserve une trace detaillee des sessions importantes (decision, implementation, validation).

## Objectif

- Garder la memoire operationnelle entre sessions.
- Retrouver rapidement le contexte d'une decision.
- Faciliter l'onboarding et la reprise par un autre intervenant.

## Convention de nommage

- Un fichier par session importante.
- Format recommande: `YYYY-MM-DD-sujet-court.md`

Exemples:

- `2026-04-20-epic14-nextjs-landing.md`
- `2026-05-03-refonte-permissions-workspace.md`

## Structure recommandee (template)

1. Contexte et objectif
2. Decisions prises
3. Changements realises
4. Tests et validations
5. Risques / limites restantes
6. URLs et environnements impactes
7. Prochaines etapes
8. References (docs, PR, commits)
