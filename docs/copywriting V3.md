## 6. Route — Timeline produit

Visuel : image 4 (timeline verticale, route avec pins).  
Placement : pleine largeur, centré.

### Copywriting

Titre (H2) :

```text
Votre transformation devient une route.
```

Sous-titre :

```text
Une trajectoire visible.
Des étapes claires.
Un cap partagé.
```

### Timeline (6 étapes)

```text
1. Prioriser les projets transformants
   (Selector — distinguer BUILD vs RUN)

2. Construire une roadmap claire
   (Maturity Roadmap — axes, chantiers, jalons)

3. Engager les équipes
   (Validation collective, vue décideur)

4. Décliner en actions concrètes
   (Plans d'action : qui fait quoi, quand)

5. Lancer réellement
   (Suivi opérationnel, rythmes visibles)

6. Piloter dans la durée
   (Ajuster, débloquer, maintenir la traction)
```

Micro-copy sous timeline :

```text
Chaque étape est un moment collectif.
Pas un automatisme.
```

CTA :

```text
[Bouton] Voir un parcours réel →
```

Action : `/workspace/demo-id/home`
